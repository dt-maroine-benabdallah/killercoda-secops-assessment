# Évaluation SecOps : niveau intermédiaire

Vous êtes d'astreinte sur un serveur Ubuntu 24.04. Vous êtes `root` sur la machine.

**Durée : 30 minutes.** Trois situations courtes, dont la correction tient en **une seule action**, une revue de plan Terraform, puis une question bonus plus complète sur les certificats.

- Étapes 1 et 2 : sécurité. Étape 3 : réseau. Étape 4 : infrastructure as code. Étape 5 : bonus (CSR et certificat).
- Prévoyez environ 5 minutes par étape et 10 minutes pour le bonus. Les étapes sont indépendantes : si vous bloquez, passez à la suivante.
- Cliquez sur **CHECK** à la fin de chaque étape pour enregistrer votre résultat. Le bouton ne bloque jamais la progression, vous pouvez le relancer après correction.
- La commande `score` affiche votre avancement à tout moment.
- Les pages de manuel (`man`) et la documentation officielle sont autorisées. Pas d'outils de scan réseau ni de bruteforce (interdits par les CGU de Killercoda).
- Expliquez à voix haute votre démarche si un évaluateur est présent : elle compte autant que le résultat.
- Votre code candidat, le démarrage, le score et la durée sont transmis à l'évaluateur. Si le code n'a pas été pris en compte au démarrage, saisissez `candidat VOTRE_CODE` dans le terminal.
